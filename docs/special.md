# Исключения, образцы и видовые связи

Четвёртый рабочий этап соответствует пункту 5 подробного плана. Входной
контракт не изменён: один объект `lemma / symbol / grammar` или массив.
Версия пакета — 0.4.0; программа работает без сети, базы слов и Perl.

```sh
python3 -m zaliz --generate examples/special.json -o forms.json
```

Этот пример возвращает код 0. В исходной группе из 77 статей по-прежнему
отсутствуют два образца, поэтому её код завершения остаётся 1.

## Нерегулярные формы

В старом проекте `txt2adb` извлекает блок исключений, а `z.x.subpatch`
сопоставляет тексту блока структуру `искл`. Генератор применяет её до обычных
правил. Python разбирает грамматические метки самого блока `△` или `Δ`,
не ищет лемму в таблице готовых слов и не исполняет текст как код.

```json
{"lemma":"брат","symbol":"мо","grammar":"1a △ мн. бра́тья; Р. мн. бра́тьев; Д. мн. бра́тьям"}
```

Выписанная форма заменяет соответствующую позицию регулярной парадигмы.
Единственное число остаётся регулярным; В. мн. заимствует Р. мн. по
одушевлённости, Т./П. мн. при отсутствии собственного исключения выводятся
из выписанного Д. мн. по правилам исходника.

Поддержаны метки:

- существительные: `И.`, `Р.`, `Д.`, `В.`, `Т.`, `П.`, с `ед.` или `мн.`;
  без числа предполагается единственное;
- `мн.` с одной формой И. мн., с пятью позициями И./Р./Д./Т./П. или шестью
  позициями И./Р./Д./В./Т./П.;
- глаголы: `наст.`, `буд.` с одной, двумя (1/3 ед.) или шестью личными формами;
  `прош.` с одной, двумя (м./ж.) или четырьмя формами; `повел.` с одной или двумя;
- `прич. действ. наст.`, `прич. действ. прош.`, `прич. страд. наст.`,
  `прич. страд.` (прошедшее), `деепр. наст.`, `деепр. прош.`;
- прилагательные: `кф` с четырьмя формами и `сравн.` с одной.

Разделы отделяются точкой с запятой. Варианты внутри позиции — `//`.
Поддержаны пометы `(затрудн.)`, `(предполож.)`, `(устар.)`, в том числе HTML-курсив.
Для сокращений можно явно задать основу: `мн. бра́ть|я, -ев, -ям, -ями, -ях`.
Явное ударение сокращённого окончания заменяет основное ударение основы.
В глагольных личном и прошедшем рядах типичные сокращения окончания выводятся
из первой формы: `буд. добу́ду, -ет`, `прош. дал, -а́`.

Зависимые глагольные формы строятся из исключений до обычного спряжения:
личные формы из 1/3 ед., императив из 3 мн., средний род и множественное
прошедшего из женского рода, действительное причастие из прошедшего мужского,
деепричастие — из причастия. Выписанное причастие склоняется именным модулем.
Собственное явное исключение имеет преимущество перед такой связью.

Полностью нерегулярный глагол может иметь `Δa:` без номера типа, например
`дать` с выписанными будущим, императивом и прошедшим. Если обязательную
позицию нельзя вывести, генерация блокируется целиком. Незаданные причастия
полностью нерегулярной статьи помечаются отсутствующими; инфинитив не
копируется в качестве якобы личной формы.

Это перенос механизма и определённой грамматики исключений, **не всего
содержимого `z.x.subpatch`**. Вложенные условные исключения, нестандартные
сокращения, ограниченные контекстом варианты и вложенные краткие ряды внутри
причастия пока требуют расширения парсера. Непонятый текст сохраняется и
блокирует генерацию. Неполная статья с индексом сама по себе не сообщает
остальные лексические исключения: программа использует только переданные данные.

## П2 и Р2

`Р2` добавляет отдельный `case: partitive`, образованный от Д. ед.
`П2`, `П2(в)`, `П2(во)`, `П2(на)` добавляют `case: locative` с ударением
на окончании. Обычные Р./П. сохраняются. Примеры: `са́хара / са́хару`,
`о ле́се / в лесу́`, `на краю́`. Условие предлога возвращается в `features.preposition`.

`[П2(в)]` факультативно: в локативной позиции допустимы и `лесу́`, и `ле́се`.
Факультативность не означает затруднительности. Указание сохраняется в
`inflection.extra_cases` как `{case, optional, preposition}`. Оно не применяется
к словам без единственного числа или неизменяемым существительным.

## Отсылочные образцы

Статья `столо́чь / св / спряж. см. затоло́чь` теперь генерируется, если в том
же массиве есть однозначно разрешённое описание `затоло́чь`, включая его
нерегулярные формы. Порядок статей произвольный; цепочки обрабатываются
итеративно, результат сохраняет входной порядок.

Перенос применяется при общей конечной части не менее трёх букв с гласной
и одинаковом положении ударения относительно неё. Начальные части заменяются
во всех формах, позиции ударений пересчитываются: `затолку́ → столку́`,
`затоло́к → столо́к`. Поддержаны и именные образцы такого строения.

Разбор образца должен быть единственным и совместимым по части речи, роду,
одушевлённости, числу; для глагола также по виду, переходности и возвратности.
Если форма изменяет заменяемое начало, не соответствует ударение, потерялось
бы побочное ударение или генерация самого образца заблокирована, возвращается
`REFERENCE_UNSUPPORTED`. Случаи другого строения требуют явного правила
переноса. Отсутствующий образец, неоднозначность и цикл по-прежнему диагностируются
на стадии анализа; никакой словарь не подгружается автоматически.

## Видовой партнёр

Римские указания I–III образуют несовершенный вид, арабские — совершенный
по таблице исходника. Поддержаны применимые сочетания типов 1–16 с
суффиксами, замены корневой гласной/конечной части и явно выписанная лемма:

```text
столкну́ть / св / 3b ◑I(-а́-)    → ста́лкивать
вы́пить   / св / 11a ◑III       → выпива́ть
ско́вывать / нсв / 1a ◑2        → скова́ть
прочита́ть / св / 1a ◑ чита́ть   → чита́ть
```

Партнёр возвращается в `generation.readings[i].aspect_partner`:

```json
{
  "status": "generated",
  "words": [{"word": {"text": "сталкивать", "accent_variants": [{"primary": [3], "secondary": [], "basis": "explicit"}]}, "stressed": "ста́лкивать", "aspect": "imperfective"}],
  "diagnostics": []
}
```

Это новое слово, а не элемент `forms`. Его индекс и полная парадигма не
выдумываются. Неприменимая помета даёт `aspect_partner.status: blocked`
и `ASPECT_PARTNER_UNSUPPORTED`, сохраняя готовую парадигму исходного глагола;
общий статус статьи становится `partial`, код CLI — 1. Без видового указания
поле `aspect_partner` не добавляется. Сложные перечисления партнёров и
контекстные комментарии требуют отдельного расширения грамматики.

## Дополнительные параграфы

Номер сохраняется в `inflection.paragraphs`.

| Параграф | Действие |
|---|---|
| §3 | Требуется существительное только мн. числа с заданным образцом |
| §7 | Краткие формы прилагательного помечаются затруднительными |
| §8–§9 | Индекс относится к самому прилагательному; отдельный омонимичный глагол или причастие не создаётся |
| §10 | Затруднительные краткие формы ед. числа, совпадающие с прошедшим глагола |
| §11 | Затруднительные регулярные краткие формы; отдельные слова со сдвигом ударения не подмешиваются |
| §13 | Обе заданные модели 6/1, у личных форм и причастий типа 1 — помета `разг.` |
| §14 | Обе заданные модели 1/6, у императива и деепричастия типа 6 — `устар.` |
| §16 | Дополнительные формы от модели на -ать; прошедшее и инфинитив остаются от -ить |

Для §§13/14 нужны оба индекса, например `6c//1a §13`; они сохраняются
в `inflection.alternatives`. §§1, 2, 4–6, 12, 15, 17, 18 и неизвестные номера
пока блокируют генерацию с диагностикой. Они не игнорируются, и полная
поддержка всех §§1–18 не заявляется.

## Проверки и различия с оригиналом

Дополнительно к прежним 666 тестам проверяются 8 статей / 233 позиции
оригинала с исключениями и П2, 60 видовых указаний, независимые языковые
примеры, отсылки, ограничения и JSON Schema. Обычное тестирование не требует
Perl. Пересоздание контрольных данных:

```sh
python3 tools/build_special_reference.py /путь/к/nlp-rus-zaliz
```

Исходный коммит фиксирован. Эталоны получены из Perl без импорта Python-движка.
Проверка включает исходные ADB-структуры, поэтому набор исключений можно
сопоставить с текстом входной статьи.

В `verb_opposite` обнаружен дефект регулярного выражения для арабских типов
9 и 14: оно требует дополнительную гласную перед `-ирать/-имать`. Например,
`впира́ть` и `вжима́ть` ошибочно остаются без преобразования. Python строит
`впере́ть` и `вжа́ть`. Для шести таких контрольных случаев сохранены оба
результата: исходный `expected`, независимый языковой `expected_corrected`
и объяснение `difference`. Остальные 54 указания совпадают с оригиналом
после унификации графического ударения односложных слов.

Различия факультативных веток предыдущего этапа описаны в
[generation.md](generation.md#проверка-спряжения). Правила `е/ё` продолжают
использовать явную словарную помету; неуказанные лексические исключения
автоматически не восстанавливаются.
